This is my project for the video game Football Manager 24. It is a shortlisting mechanism for html exports from the game.

How it works: 
On the streamlit interface the user is able to upload and html export taken from the game. 
The export is loaded and the user is able to filter through player role and age, choosing the top N players they would like to be 
recommended. The site then gives the reasoning as to why players are ranked where they are, showing the weights for the attributes in each role. 

What it's built with:
The project uses python libraries with a simple streamlit interface
